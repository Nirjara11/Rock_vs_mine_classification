# Rock vs Mine Prediction Using Machine Learning

Project Overview:
This project uses a Machine Learning model to classify sonar signals as either Rock(R) or Mine(M).
The model is trained on the sonar dataset, which contains numerical measurement of sonar signals reflected from diffrent underwater objects. A Logistics Regression classifier is used to learn patterns from the data and predict whether an object is a rock or a mine.

Dataset Information:
Dataset: Sonar Dataset
Number of Feature: 60
Target classes: R = Rock 
                M = Mine

Technologies Used:
Python | NumPy | Pandas | Scikit-Learn | Jupyter Notebook

Machine Learning Workflow:
1. Import the Libraries
2. Load the dataset
3. Explore and Preprocess the data
4. Separate feature and target labels
5. Split the dataset into training and testing datasets
6. Train the Logistic Regression Model
7. Evaluate the model performance
8. Build a prediction system for new input

Model Used:
Logistic Regression was used as the classification algorithm to predict whether a sonar signal corresponds to a rock or mine.

Results:
Training Accuracy: 0.8342245989304813
Testing Accuracy: 0.7619047619047619
